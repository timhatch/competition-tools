# Competition Tools

A collection of tools to assist Jury Presidents and other competition officials with common (and uncommmon) competition management tasks.

## Para-Jenga

An HTML/Javascript Single Page Application (SPA) to create a combined starting grid for para competitions, showing when each sport class and athlete is scheduled to start on each qualification route.

## Boulder Restart Assistant

A SPA tool to assist competition officials in planning the introduction of gaps/interrupts in the rotation plan for boulder qualification/semifinals.
The tool:
- allows for the suspension/resumation of a round as well as the introduction of "gaps" if any athletes need to restart on a boulder.
- automagically calculates where any gap needs to be introduced given the number of boulders in the round, the boulder and athlete concerned, and any time delay on decision-making. 
- shows the impact of any gap addition or interruption call zone and transit zone plans, allowing these to be printed for distribution to comeptition staff.
